# Knowledge module notes

Workspace adaptations of the documentation playbooks (`document-handling.md` routes them); a project may override them in `AGENTS.md`. Folder roles, dates, status marks and generated lists are owned by `AGENTS.md`, `conventions.md` and `document-format.md`.

- **Parameters.** Priority timelines and similar settings go in `AGENTS.md`.
- **Conversation conduct.** The self-monitoring section of `document-thinking.md` governs conduct, not documents.
- **Readers.** Give a newcomer a `README.md` in the work area or a guide named for the task or subject, in `docs/` or beside the work. Keep steps and the reason for them in separate, linked documents. Give a step-by-step guide `covers:` or `review_by` so stale checks flag it (`conventions.md`).
- **Numbering.** Refer to sections by name in project documents (`conventions.md`); number only procedure steps, stable ids and playbook sections that other files cite by number.
