# Tools

Tools for this project's own work: converters, build or data helpers, scripts worth keeping. Workspace tools (`ws` and its helpers) go in `_steering/_toolstore/`, not here (`conventions.md`). One folder per tool, with a `README.md` (front matter `kind`, `description`), the code and `tests/`; follow `_steering/_toolstore/README.md`. List them with `ws map _tools/`.
