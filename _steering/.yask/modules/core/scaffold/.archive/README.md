# Archive

Retired material keeps its relative path (for example `.archive/_workboard/meetings/...`). `ws archive` deleted its git history when it moved here, so it cannot be recovered from git. The hidden folder is skipped by most tools; `.ignore` covers the rest. Heavy or sensitive files go to cold storage outside git; record them in `manifest.md`. See `archive-and-retention.md` and `AGENTS.md` for the folder role.
