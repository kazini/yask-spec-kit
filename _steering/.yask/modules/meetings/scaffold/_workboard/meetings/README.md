# Meetings

One folder per meeting, with a stamped name (see `_steering/.yask/conventions.md`). `summary.md` is one page from `_steering/.yask/templates/meeting-summary.md`: decided, requested, pending and dates, with a first line saying it is evidence. `transcript.md` holds redacted verbatim text; search it, never read it whole.

Procedure: `_steering/.yask/playbooks/ingest-meeting.md`. The index is generated; do not hand-maintain one.
