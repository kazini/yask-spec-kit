# Workboard

Planning and organizing: drafts, open items, unreviewed raw material, proposals and each person's log. Humans and agents both work here. Settled work moves to its owning folder in the project root (the fact map is in `AGENTS.md`) and may also be created there directly. Raw material (`meetings/`, `reports/`) is evidence, never canon: search it, do not read it whole. Subfolders describe themselves (`ws map _workboard/`). Heavy files stay outside git (`.archive/manifest.md`); retired items move to `.archive/`.
